## 🎯 Как использовать

### Для разработчиков

1. **Сборка проекта**
   ```bash
   cd frontend
   npm install
   npm run build
   ```

2. **Генерация иконок**
   ```bash
   # Вариант 1: Через скрипт (требует sharp или ImageMagick)
   npm run pwa:generate-icons
   
   # Вариант 2: Через браузер
   # Откройте public/icon-generator.html
   # Загрузите исходную иконку и скачайте результат
   ```

3. **Проверка PWA**
   ```bash
   npm run pwa:check
   ```

4. **Очистка кэша**
   ```bash
   npm run pwa:clear-cache
   ```

### Для пользователей

1. **Установка на устройство**
   - Android: Chrome → Меню → "Установить приложение"
   - iOS: Safari → Поделиться → "На экран Домой"
   - Desktop: Chrome → Иконка установки в адресной строке

2. **Синхронизация**
   - Все операции автоматически синхронизируются
   - Статус отображается в интерфейсе
   - Офлайн режим работает автоматически

## 🔧 Требуется от бэкенда

### Необходимые эндпоинты

Документация: `backend/PWA_SYNC_API.md`

Основные эндпоинты:
- `GET /api/sync/changes` - получить изменения
- `POST /api/sync/operation` - отправить операцию
- `POST /api/devices/register` - зарегистрировать устройство
- `DELETE /api/devices/:deviceId` - отменить регистрацию
- `GET /api/devices` - список устройств
- `POST /api/settings` - сохранить настройки
- `GET /api/settings` - получить настройки

### WebSocket события

Клиент → Сервер:
```json
{
  "type": "sync",
  "deviceId": "device_123",
  "syncType": "message|messages_read|chat_updated|...",
  "payload": { ... }
}
```

Сервер → Клиент:
```json
{
  "type": "sync",
  "syncType": "message",
  "payload": { ... }
}
```

### База данных

Требуемые таблицы:
- `devices` - устройства пользователя
- `sync_queue` - очередь синхронизации
- `sync_changes` - история изменений
